# IA Revisor Vial — Versión 1.3
Aplica al GS la lógica del artículo 3.6.11 letra b) del DS N°30:
- Base <=85% y Proyecto <=85%: sin observación normativa.
- Base <=85%, Proyecto >85% y Mitigado <=85%: mitigación restablece umbral.
- Base <=85%, Proyecto >85% y Mitigado >85%: observación normativa.
- Base >85%: Mitigado no debe aumentar más de 1 punto porcentual respecto de Base.
- Datos incompletos: revisión profesional.
La matriz final sólo remite observaciones normativas y casos sin trazabilidad.

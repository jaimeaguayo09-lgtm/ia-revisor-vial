# IA Revisor Vial — Prototipo 0.7

Revisión priorizada por arco y período.

- Consolida Actual → Base → Proyecto → Mitigado.
- Calcula variaciones porcentuales.
- Prioriza alertas: ALTA, MEDIA y REVISIÓN.
- ALTA: >100% o aumento Base→Proyecto >=10 puntos porcentuales.
- MEDIA: >85% o aumento >=5 puntos porcentuales.
- REVISIÓN: variaciones menores trazables.
- La prioridad es una regla de triage técnico del prototipo; no equivale a incumplimiento normativo.
- Mantiene PDF y CSV.

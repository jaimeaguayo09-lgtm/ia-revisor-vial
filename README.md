# IA Revisor Vial — Prototipo 0.3

Versión enfocada en reducir falsos positivos.

- exige expresiones explícitas del mismo concepto antes de comparar cantidades;
- separa estacionamientos vehiculares, bicicletas y PMR;
- muestra evidencia independiente para cada valor en conflicto;
- si la evidencia no demuestra el hallazgo, no emite observación;
- mantiene CSV e Informe de Observaciones PDF.

Main file: `app.py`.
